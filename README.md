# Система управления заявками на закупку

## Назначение

Консольное приложение для оформления заявки на закупку товара и проверки возможности её согласования.

## Целевая аудитория

Сотрудники организации, создающие заявки на закупку, и руководители, которые их согласуют.

## Предметная область

Закупка товаров для нужд организации: сотрудник указывает товар и его стоимость, после чего заявка получает статус согласования.

## Основные сущности

- Заявка на закупку
- Сотрудник
- Товар
- Согласование

## Основные функции

- Создание заявки с указанием сотрудника, товара и количества
- Расчёт общей стоимости закупки
- Проверка возможности согласования заявки по лимиту бюджета
- Вывод статуса согласования

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
